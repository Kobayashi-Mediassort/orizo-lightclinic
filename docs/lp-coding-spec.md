## 4. 表示仕様

### 4.1 共通

- PC・スマホ共通で、LP本体の基準コンテンツ幅は `780px`
- デザイン再現の基準はFigmaの `780px` 幅デザインとする
- LP本体から横スクロールが出ないようにする

### 4.2 PC表示

- 画面幅が `781px` 以上の場合:
  - LP本体幅は `780px`
  - ブラウザ中央に配置
  - Figma上のサイズは基本的に `px` で再現
- 画面背景が見える場合は、LP本体との差が分かる控えめな背景色を設定する

### 4.3 スマホ表示

- 画面幅が `780px` 以下の場合:
  - LP本体は画面いっぱいに表示する
  - `width: 100%`
  - Figmaの `780px` デザインを基準に、テキスト、パディング、サイズ、マージン等を `vw` で縮小する
- 単純な `transform: scale()` による全体縮小は使用しない
  - クリック領域、スクロール高さ、アクセシビリティに問題が出るため

## 5. Sass仕様

### 5.1 方針

- CSSはSass形式で編集できるようにする
- 開発時はSassを編集し、納品時はコンパイル済みCSSを `assets/css/style.css` として配置する
- `780px` 以下の縮小指定用にSass関数を用意する

```scss
@function vw($px, $base: 780) {
  @return calc($px / $base * 100vw);
}
```

### 5.2 指定例

```scss
.lp {
  width: 780px;
  margin-inline: auto;
  overflow: hidden;
  background: #fff;
}

@media (max-width: 780px) {
  .lp {
    width: 100%;
  }

  .section {
    padding: vw(48) vw(32);
  }
}
```

### 5.3 注意点

- PC表示ではFigmaの `px` 値を基準にする
- スマホ表示では `vw()` を使い、デザイン比率を保って縮小する
- 可読性やタップ領域の確保が必要な箇所は `clamp()` を併用する

```scss
font-size: clamp(12px, vw(24), 24px);
```

## 6. 画像・WebP化仕様

### 6.1 画像書き出し

- 画像素材はFigmaから書き出す
- 書き出し元は開発用ディレクトリに保持する
- 納品物ではWebP形式の画像を参照する

### 6.2 WebP化

- 画像はビルド時または納品前処理で自動的にWebP化する
- 推奨ツール:
  - `sharp`
- 目安:
  - 写真系: WebP品質 `80〜90`
  - 透過画像: 見た目劣化がない設定で変換
- 変換後、Figmaとの見た目差分が大きい画像は品質を調整する

### 6.3 alt

- 装飾画像: `alt=""`
- 医師、院内、説明図、アクセス、料金に関わる画像: 内容が伝わるaltを設定
- 重要情報が画像内だけに閉じないよう、CTAや見出し、主要訴求はHTMLテキストで実装する
